# Disable-Hyper-V-And-VBS

# ENGLISH

> [!WARNING]
> ### 🛑 CRITICAL STEP: REMOVE YOUR WINDOWS HELLO
> You **MUST** remove your Windows PIN, and Face ID / Windows Hello **BEFORE** running this script. If you skip this, you will be locked out of your account after the reboot.

---

## 🚀 How to Use

1. Download [dgreadiness_v3.6](https://github.com/KilluaUwU/Disable-Hyper-V-And-VBS/releases/download/dgreadiness_3.6.zip/DisableHyperVandVBS.zip)
2. Unzip
3. Right-click DisableAll.bat and select "Run as Administrator".
4. Wait and restart PC after it asks for restart. Will look like this:
<img width="985" height="514" alt="image" src="https://github.com/user-attachments/assets/c1cc2627-c3e4-4d88-9493-201250670d85" />
5. Press F3 on start screen when it asks (both times)
