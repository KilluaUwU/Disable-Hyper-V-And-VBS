# Disable-Hyper-V-And-VBS

# ENGLISH

> [!WARNING]
> ### 🛑 CRITICAL STEP: REMOVE YOUR WINDOWS HELLO
> You **MUST** remove your Windows PIN, and Face ID / Windows Hello **BEFORE** running this script. If you skip this, you will be locked out of your account after the reboot. \n
> If "Remove" button at pin-code is grayed out disable option "For improved security, only allow Windows Hello sign-in for Microsoft accounts on this device" in sign-in options additional settings(below password options) or sign-in with local account.
---

## 🚀 How to Use

1. Download [DisableHyperVandVBS](https://github.com/KilluaUwU/Disable-Hyper-V-And-VBS/releases/download/dgreadiness_3.6.zip/DisableHyperVandVBS.zip)
2. Unzip
3. Right-click DisableAll.bat and select "Run as Administrator".
4. Wait and restart PC after it asks for restart. Will look like this:
<img width="985" height="514" alt="image" src="https://github.com/user-attachments/assets/c1cc2627-c3e4-4d88-9493-201250670d85" />
5. Press F3 on start screen when it asks (both times)

## ❌ To enable VBS and Hyper-V back

1. Download [DisableHyperVandVBS](https://github.com/KilluaUwU/Disable-Hyper-V-And-VBS/releases/download/dgreadiness_3.6.zip/DisableHyperVandVBS.zip)
2. Unzip
3. Right-click EnableAll.bat and select "Run as Administrator".
4. Wait and restart PC after it asks for restart.
5. Press F3 on start screen if it asks (both times)

## 🚨 If VBS and Hyper-V reenable after pc restart

> [!WARNING]
> DisableAll script will auto-startup on pc launch.

1. Right-click EnableAll.bat and select "Run as Administrator".
2. Wait and restart PC after it asks for restart.
3. Press F3 on start screen if it asks (both times)

## 🚀 Как использовать

1. Загрузите [DisableHyperVandVBS](https://github.com/KilluaUwU/Disable-Hyper-V-And-VBS/releases/download/dgreadiness_3.6.zip/DisableHyperVandVBS.zip)
2. Распакуйте
3. Правой кнопкой мыши по DisableAll.bat и выберите "Запуск от имени Администратора".
4. Подождите пока скрипт не попросит перезапустить ПК. Будет выглядеть так:
<img width="985" height="514" alt="image" src="https://github.com/user-attachments/assets/9c3b9255-e78e-4860-8218-4a203268f07d" />
5. Во время запуска появятся окна с текстом, нажимайте F3 пока они не пропадут

## ❌ Для включения VBS и Hyper-V обратно

1. Загрузите [DisableHyperVandVBS](https://github.com/KilluaUwU/Disable-Hyper-V-And-VBS/releases/download/dgreadiness_3.6.zip/DisableHyperVandVBS.zip)
2. Распакуйте
3. Правой кнопкой мыши по EnableAll.bat и выберите "Запуск от имени Администратора".
4. Подождите пока скрипт не попросит перезапустить ПК.
5. Во время запуска могут появиться окна с текстом, нажимайте F3 пока они не пропадут

## 🚨 Если VBS и Hyper-V снова активны после перезапуска пк

> [!WARNING]
> Скрипт для отключения VBS и Hyper-V будет запускаться автоматически вместе с ПК.

1. Правой кнопкой мыши по AutorunDisableOnWindowsStartup.bat и выберите "Запуск от имени Администратора".
2. Подождите пока скрипт не попросит перезапустить ПК.
3. Во время запуска ПК могут появляться окна с текстом, нажимайте F3 пока они не пропадут.
